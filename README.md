## 📌 Sobre el Repositorio

Este repositorio contiene la recopilación de **ejercicios prácticos, maquetaciones y diseños web en HTML5 y CSS3** desarrollados durante el segundo curso del Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW) en el **I.E.S. Politécnico Hermenegildo Lanz**.

El objetivo de este espacio es afianzar la estructura semántica, el diseño responsivo, los sistemas de posicionamiento moderno y la estilización avanzada del lado del cliente utilizando **Visual Studio Code** en un entorno optimizado.

## 📂 Contenido y Prácticas

El código está estructurado para abordar diferentes conceptos clave de diseño y maquetación web:

- **Estructura Semántica y Accesibilidad:** Uso correcto de etiquetas HTML5, SEO básico y buenas prácticas de accesibilidad web.


- **Diseño y Estilos Avanzados (CSS3):** Selectores avanzados, variables CSS (Custom Properties), tipografías y paletas de colores.


- **Layouts Modernos (Flexbox y Grid):** Creación de estructuras flexibles, alineaciones complejas y diseño de rejillas adaptables.


- **Diseño Responsivo y Media Queries:** Adaptabilidad de interfaces para dispositivos móviles, tablets y escritorios (Mobile First).
